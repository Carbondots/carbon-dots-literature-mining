# Representative cases from the 105-paper independent audit

This directory provides two source-grounded cases corresponding to operational categories reported in Supplementary Table S19.

| Case | Table S19 operational category | Review status |
| --- | --- | --- |
| [Case 2197](case_2197_sample_reconstruction/) | Sample reconstruction | Source-grounded review completed |
| [Case 2297](case_2297_sample_property_attribution/) | Sample–property attribution | Source-grounded review completed |

The Table S19 categories follow the first-observable-deviation framework. Case 2197 is therefore classified under **Sample reconstruction**; downstream property relations are documented as consequences of that sample-level deviation rather than as a second Table S19 category. Case 2297 is classified under **Sample–property attribution**.

Each case retains the frozen workflow output used in evaluation and provides source locators, an annotated source PDF, selected trace information, and the completed source-grounded review outcome.

The public corpus ID is used as the primary identifier. Legacy processing IDs are retained only to locate the corresponding archived workflow output.
