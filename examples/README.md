# Examples

This directory provides source-grounded examples accompanying the manuscript and reviewer responses.

- [`workflow_examples/`](workflow_examples/): four representative examples illustrating sample anchoring, measurement-state handling, precursor–quantity pairing, and source-grounded reconciliation.
- [`independent_audit_cases/`](independent_audit_cases/): two representative cases from the 105-paper independent audit, aligned with the operational categories reported in Supplementary Table S19.

Each case includes an annotated source PDF and the available source evidence, archived workflow output, structured record, or review decision needed to trace the case.
