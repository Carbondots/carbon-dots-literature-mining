# Workflow protocol

This protocol maps the public extraction workflow to the accompanying prompt, rule, field, and source-location resources. The executable implementation is maintained in `preprocess/`, `synthesis_mining/`, `property_mining/`, and `mining_ML_Em/`.

## Execution order

1. `preprocess/01_pdf_to_markdown.py` converts PDFs into document folders. `02_latex_to_text.py` performs conservative LaTeX and unit-text conversion, `03_trim_markdown_tail.py` removes recognized document tails, and `04_tokenize_markdown.py` emits section-aware sentence files with block, paragraph, and sentence anchors.
2. Synthesis steps 01-02 segment the tokenized text and apply cosine-based candidate filtering. The associated experiment-template resource is provided under `normalization_resources_20261005-020250/`.
3. Synthesis steps 03-06 use stage-specific prompts for semantic screening, evidence refinement, sample-name extraction, and table reconstruction. The exported prompt templates are provided in this directory.
4. Synthesis steps 07-09 merge repeated structured outputs, normalize article-specific abbreviation/full-name relations, and perform targeted field review. Deterministic checks and LLM-based semantic decisions are indexed in `rules_20261005-020250.csv`.
5. Property steps 02-03 identify property-bearing candidate sentences and process relevant tables. Step 04 uses synthesis-side sample context for initial sample/property decisions. Steps 05-13 refine, clean, classify, bind, review, structure, and reconcile property relations. Step 14 exports the final property fields recorded in `field_schema_20261005-020250.csv`.
6. `mining_ML_Em/` contains the downstream molecular-featurization, article-grouped evaluation, model-training, and feature-ablation workflow used for the Em analysis.

## Resource map

- `prompt_catalog_20261005-020250.csv`: prompt identifiers, stages, source functions, inputs, and output requirements.
- `prompt_components.md` and `prompt_components_catalog_20261007-000613.csv`: supporting functions, constants, and formatting components referenced by the prompts.
- `rules_20261005-020250.csv`: deterministic and semantic decision rules across workflow stages.
- `field_schema_20261005-020250.csv`: implementation fields, formats, missing representations, and source locations.
- `SOURCE_MAP_20261005-020250.csv`: links between documented workflow elements and public implementation files.
- `normalization_resources_20261005-020250/`: retrieval templates and normalization-resource notes.
