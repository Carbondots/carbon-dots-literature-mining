# Prompt and rule resources

This directory provides 28 exported prompt templates and 32 source-matched supporting components, together with the workflow protocol, prompt catalogs, field schema, operational-rule inventory, source-location mappings, and normalization resources.

The prompt templates preserve the operational instructions, dynamic inputs, and expected output formats used at the corresponding workflow stages. The component files document supporting rule functions, constants, and formatting elements referenced by those templates. The source map and catalogs identify the corresponding implementation modules and functions in the public repository.

The field-schema file is an implementation-field inventory. Formal evaluation definitions and scoring rules are provided in the manuscript and Supplementary Information.
