# MatSciBERT synthesis extraction outputs

This folder contains the article-level synthesis-condition outputs generated by a MatSciBERT-based baseline on the development corpus used in this study.

The extraction fields were obtained as follows:

- `CD_Sample_Name`, `Precursor_Identity`, and `Solvent_Identity` were generated using the MatSciBERT-based entity-extraction route.
- `Reaction_Temperature`, `Reaction_Time`, and `Microwave_Power` were identified using regular-expression patterns.
- The remaining columns retain the corresponding fields from the original output table.

The CSV contains the direct outputs of this baseline. No manual correction, CD-specific sample expansion, shared-condition inheritance, semantic-role reassignment, or relation completion was applied. Consequently, the table preserves article-level candidate outputs rather than reconstructed sample-level synthesis records.

Blank cells and `N/A` indicate that no corresponding output was returned. `Paper_ID` follows the internal identifiers of the development corpus.
